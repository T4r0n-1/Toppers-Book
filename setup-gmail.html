Connect Gmail practice alerts

Use codetoppers@gmail.com. Setup stays free within Google's quotas. This script checks every 15 minutes and attempts up to 90 student alerts per rolling 24 hours, leaving room for other email. No student email is sent during initial setup.

  1. Open Google Apps Script ↗ with codetoppers@gmail.com. Create a New project called Toppers Practice Alerts.
  2. Copy the code below, replace everything in Code.gs, and save.
  3. Select setupPracticeAlerts in the function menu and click Run. Review and grant the Google permissions for your own project. It needs to send mail, connect to the website, and manage its time trigger.
  4. Open Apps Script Project Settings → Script properties. Copy the generated PRACTICE_MAILER_SECRET value privately. Do not share it in chat or screenshots.
  5. In Cloudflare: Workers & Pages → toppers-book → Settings → Variables and Secrets → Add. Add a production Secret named PRACTICE_MAILER_SECRET with that value. Save, then redeploy/retry the latest production deployment so the secret takes effect.
  6. Return to Apps Script, select startPracticeAlerts, and click Run. This checks the connection, attempts one test email to codetoppers@gmail.com, and schedules the automatic trigger. No web-app deployment is needed.

After setup, tell us whether the test email arrived. Alerts will announce newly published papers added to the paper list; existing practice questions are not announced retrospectively. Students can unsubscribe in each email or turn alerts off in Edit profile. To stop the sender, run stopPracticeAlerts.
